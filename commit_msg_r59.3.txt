fix(webui): R59.3 — WebUI не подключается к балансеру (monitor iframe 401 + WebSocket crash)

User report: "WebUI не подключается к балансеру и не определяет свое поведение"

Headless диагностика (Playwright + scripts/diag_webui.py) нашла 2 независимых бага:

1) monitor.html iframe шлёт все API запросы БЕЗ X-API-Token → 401
   - webui/js/monitor/api.js:14 имел fallback chain: ?token= → localStorage.apiToken → ''
   - Когда monitor.html загружается как iframe из index.html, ни ?token=,
     ни localStorage не заполнены → токен пустой → 401
   - 11/27 запросов в логе (cluster, queue, sessions, autopull, candidates,
     virtualmodels, models/operations) → все 401
   - fix: добавить 3-й fallback (window.WEBUI_CONFIG.API_TOKEN) в api.js
   - fix: загрузить config.js в monitor.html (<script defer> в <head>)
   - fix: добавить defer на все script src в monitor.html, чтобы config.js
     выполнился ДО init.js (sync init.js вызывает fetchAll() сразу,
     который читает токен — без defer defer config.js не успевал)

2) app.js init() падает: "Cannot read properties of undefined (reading 'connect')"
   - webui/js/modules/websocket.js создавал const WebSocketManager = (function(){...})()
     но НЕ присваивал window.WebSocketManager = WebSocketManager
   - app-listeners.js:274 вызывает window.WebSocketManager.connect() → crash
   - Симптом: connection status badge застревает на "Connecting..."
   - Стало падать молча с момента 9d12d6a "recretae api / refactor webui"
     (28 апреля); до R57.x split ошибка тоже была, но не замечали
     (WebUI доходил до конца init)
   - fix: добавить `if (typeof window !== 'undefined') { window.WebSocketManager = WebSocketManager; }`
     в конец websocket.js (по аналогии с api.js:441-443)
