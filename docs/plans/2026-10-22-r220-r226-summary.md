## Найденный по ходу дефект R224 (важно для будущих правок)

Авто-выгрузка после потери сессии сначала освобождала модель ПО ИМЕНИ. На живом прогоне
(пара контейнеров мастер+узел) следующий запрос успевал перезагрузить модель раньше, чем
горутина выгрузки доходила до дела, — и `UnloadModel(name)` освобождал свежий инстанс: контейнер
падал с `exit code 2`, модель исчезала из реестра. Теперь `unloadModel(name, expect)` сверяет
указатель под `b.mu`; при расхождении выгрузки нет (`instance_replaced`). Правило на будущее:
любая асинхронная операция над моделью должна сверять ИНСТАНС, а не только имя.
## Решения, которые стоит помнить

1. **Аутентификация живёт в балансере, не в образе `webui`.** Образ — nginx со статикой + прокси
   на `API_HOST:API_PORT`. Перенос одного образа на другую машину не даёт входа (см.
   `docs/features/webui-auth.ru.md`).
2. **Токен в страницу не вшивается.** Единственный путь для браузера — сессия; break-glass токен
   вводит оператор, значение живёт в `sessionStorage` вкладки.
3. **Потеря узла раскладки — событие, а не таймер.** Диагностика и авто-выгрузка срабатывают по
   факту сбоя ввода-вывода/инференса. Вотчдог по pid/uptime сознательно НЕ делали.
4. **Сессии переживают рестарт, но не разделяются между инстансами балансера.** Для двух
   инстансов нужен sticky-роутинг или внешний store (Redis) — не сделано, см. ниже.
5. **Тесты должны падать на настоящей регрессии.** За сессию исправлены три «врущих» теста:
   пробник R221 (зелёный без патча, потому что проверял pre-request гейт), `TestR173` (порт
   `+1000` выходил за 65535), живая регрессия (FAIL вместо PRECONDITION на выгруженной модели).

## Что осталось (приоритеты)

1. **Мульти-балансер**: сессии между инстансами не разделяются. Варианты — sticky на фронте
   (дёшево), файл на общем томе с flock (средне), Redis-стор (дорого, но настоящий HA).
2. **Донор недоступен** (exit-node): не сделаны A/B скорости с раскладкой, две модели
   одновременно, обновление образа донора до `r221+`, повторный прогон пробника на настоящем
   доноре.
3. **`plans/` и docs для старых раундов** (R214–R219) — сведены в CHANGELOG, отдельных планов нет.
4. **Разовый флейк** `go test ./internal/balancer/` (одно падение в серии, 6 повторных — чисто);
   при повторе добавить `-count=2` и разобрать конкретный тест.
5. **`_diag/`** — временные скрипты и логи (в .gitignore и .dockerignore); генератор патча
   перенесён в `scripts/make-rpc-session-patch-r221.js`.
