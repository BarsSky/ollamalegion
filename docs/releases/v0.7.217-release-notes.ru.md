# OllamaLegion v0.7.217 — заметки о релизе

Технический релиз после `v0.7.216`: гигиена репозитория, починка тестов, которые падали от
состояния хоста, и дочистка английских переводов. Новых возможностей нет — только надёжность
ворот и чистота дерева.

## Что вошло

| Тема | Что сделано |
|---|---|
| Гигиена | Дерево освобождено на 441 МБ (691 → 214 МБ): удалены `debug/`, `_diag/`, `loadtest-reports/`, `test-results/`, `data/`, корневые `*.exe`/`*.log`/`*.7z`, 15 бэкапов `deployments/.env.bak-*`, `__pycache__`, старые архивы `dist/`. |
| Дефект репозитория | `.gitignore`-правила `plan.md` и `DEPLOYMENT.md` были без слэша и на Windows матчились на любой глубине: в git не попадали `docs/getting-started/deployment.md` (английская пара!) и `docs/plans/*/PLAN.md`. Правила сделаны якорными, файлы добавлены — `verify-docs-complete` видит 39 пар. |
| Тесты | R133-тесты `cmd/cppworker` больше не зависят от локального артефакта `cmd/cppworker/config/` (повторяют путь `main()` через `rpcConfigFromEnv`); `internal/sdbackend` переживает занятый temp-каталог на Windows (`tempDirTolerant`); тесты с 5-ГиБ разряжённым файлом при нехватке места **пропускаются** с явной причиной (`ENOSPC -> skip`), а не краснеют. |
| Переводы | Дочищены русские абзацы в EN-документах: `bridge-api.md` (вступление, сноски, «Оглавление»), `balancer-cppworker-contract.md` (блоки R113/R108); нормализован регистр `llm` → `LLM`. |
| Ворота | `run-checks.ps1` предупреждает, что параллельный `go test` даёт средовые падения; сам прогон остался 4 шага: Go-пакеты, JS, CUDA-селфтест, ворота локализации и документации. |

## Диск и образы (локальное окружение, не часть кода)

- Docker: удалены неиспользуемые образы старше 24 ч и кэш сборки (−50 ГБ внутри VM); активные
  образы стенда не тронуты, но старые теги r228/r229 удалены — для отката их нужно пересобрать.
- Windows: очищены Go-кэш, `%TEMP%` и npm-кэш; VHDX Docker сжат пользователем (свободно 76 ГБ).
- Новые образы: `balancer`/`webui` — `r236-i18n`, `agent` — `r237-i18n`, `cppworker:gpu` —
  `r237-i18n` (с кодом синхронизации языка).

## Как обновиться

Обновление необязательное: поведение не меняется, меняются тесты, `.gitignore` и тексты
документации. Достаточно `git pull` (ветка `centurion`). Пересборка образов нужна только если
вы хотите включить язык логов на воркерах.
