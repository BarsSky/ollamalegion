chore(release): v0.5.9 — documentation audit + security fix + 3 pre-existing test-bug fixes

Документационный аудит + закрытие давнего todo "проверить корректность
документации и убрать личную информацию". Закрывает 1 утечку креда
(GitHub PAT в публичном скрипте) и 3 бага в тестах v0.5.6/v0.5.7, которые
не проявлялись в production (тесты не запускались в CI), но блокировали
go test ./... в среде разработчика.

## Security: убран реальный GitHub PAT

- scripts/run-setup-runner-elevated.ps1: заменён реальный (истёкший)
  registration token формата AHO* на $env:GITHUB_REGISTRATION_TOKEN
  с инструкцией получить новый через GitHub UI. Все остальные CI
  scripts уже использовали env vars — этот был единственным outlier.

## Документационный аудит

- IP-адреса: 100+ специфических 192.168.x.x заменены на RFC5737
  192.0.2.x в конфигах, скриптах, документации. Стандартные RFC1918
  ranges (172.17-172.31/16, 10.0.0.0/8, 192.168.0.0/16) сохранены —
  это не personal, а технические подсети.
- Example IPs в demo data: 10.0.0.50/55 в cmd/monitor/monitor.html
  и webui/js/monitor/api.js гармонизированы с уже использованным
  192.0.2.100.
- Test fixtures: 10.0.0.1 в plans/, 10.99.99.99 в cline_routing_test.py
  → RFC5737.
- nctxReload harmonized: config/config.example.json приведён к
  config/config.json (131072/120, было 262144/90).
- .env.bundled* policy: реальные .env.bundled, .env.bundled-full,
  .env.bundled-with-agent, .env.cocoindex, .env.llama добавлены в
  .gitignore. В репо остаются только .example шаблоны. 3 файла
  удалены из индекса (реальные config'и остались на диске, untracked).
- Real tokens: 4 вхождения JH678MNSJNDAJNDSK → placeholder
  changeme-bundled-with-agent-token-please-change.
- .env.bundled renamed to .env.bundled.example (всё содержимое — шаблон).
- .env.bundled-full renamed to .env.bundled-full.example.
- .env.bundled-with-agent deleted from index (real config on disk).

## docker-compose: fix start-bundled-full.ps1

- scripts/start-bundled-full.ps1:89: битый путь
  "& $PSScriptRoot\help\..\deployments\.env.bundled-full.example"
  (всегда fail) заменён на Copy-Item через $DeployDir.
  Теперь свежий юзер после git clone может запустить

## 3 pre-existing test-bug fix'а (v0.5.6/v0.5.7)

- internal/cppbackend/metrics_test.go: off-by-one в expected
  percentiles (172/287/298 → 173/288/298, nearest-rank формула
  sorted[N*p/100] для N=256). Добавлен import "time" (time.Millisecond
  использовался, но не импортирован).
- internal/cppbackend/user_tracker_test.go: TestUserTracker_Concurrent
  был racy (каждый горутин делал TryAcquire → Release немедленно,
  что позволяло 100 горутинам все пройти при max=4). Переписан на
  peak concurrent tracking через atomic CAS.
- cmd/cppworker/user_id_test.go: 2 неверных ожидания sanitize
  (код сохраняет @ для email-like IDs, тест ждал замены на _).
  Убран unused import "net/http".
