#### Известные ограничения
- При передачи проксируемых запросов обратно идет ответ судя по его содержанию только от одного сервера, а не суммированный балансером. 
- Сервер А имеет модели одни, а сервер Б другие. При проксировании модель сервера Б не видна. Следовательно нет возможности отправить ей стандартный запрос по API.

- Отсутствует полное повторение API (если судить по документации):
  - api/show
  - api/create
  - api/copy
  - api/pull
  - api/push
  - api/delete
  - api/version

- API должно проходить через контроль балансировщика, если это не существующая сессия генерации и чата (чтобы не перегружать сеть и не нагружать балансировщик).

- По активным сессиям не понятно: постоянно происходит смена порта — это так и должно быть, и из-за того что логи сыпятся скопом, сложно понять что происходит и с каким сервером.
