▼ Настройки llama.cpp / GGUF

Глобальные параметры загрузки GGUF-моделей. Применяются ко всем llama.cpp бэкендам. Могут быть переопределены на странице GGUF для конкретной модели.

? Число слоёв модели для выгрузки на GPU. -1 = все слои (максимальное ускорение), 0 = только CPU.
? Размер контекстного окна в токенах. Больше = длиннее диалоги, но больше потребление VRAM/RAM.
? Размер батча для инференса. Больше = быстрее на GPU, но больше потребление памяти.
? Доли тензоров для каждого GPU через запятую (например: 0.5,0.5). Сумма должна быть 1.0. Используется только при стратегии Manual.

Per-Model Profiles (n_ctx override)

Per-model profile переопределяет contextLength для конкретной GGUF-модели. Применяется в 3-tier резолвере между body и per-backend default. Используйте это для моделей с большим окном (gemma-4 — до 256K) или для ускорения малых моделей коротким окном.

Нет настроенных профилей. Создайте первый, чтобы переопределить n_ctx для конкретной модели.
