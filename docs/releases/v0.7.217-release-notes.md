# OllamaLegion v0.7.217 - release notes

A maintenance release after `v0.7.216`: repository hygiene, tests that no longer fail because of
the host state, and the last Russian leftovers in the English docs. No new features - only
reliable gates and a cleaner tree.

## What is inside

| Theme | What was done |
|---|---|
| Hygiene | The tree lost 441 MB (691 -> 214 MB): `debug/`, `_diag/`, `loadtest-reports/`, `test-results/`, `data/`, root `*.exe`/`*.log`/`*.7z`, 15 `deployments/.env.bak-*` copies, `__pycache__`, old `dist/` archives were removed. |
| Repository defect | The `.gitignore` rules `plan.md` and `DEPLOYMENT.md` had no leading slash and on Windows matched at any depth, so git never saw `docs/getting-started/deployment.md` (an English pair!) and `docs/plans/*/PLAN.md`. The rules are anchored now, the files are tracked, and `verify-docs-complete` reports 39 pairs. |
| Tests | The R133 tests in `cmd/cppworker` no longer depend on the local artifact `cmd/cppworker/config/` (they follow the `main()` path via `rpcConfigFromEnv`); `internal/sdbackend` survives a busy temp directory on Windows (`tempDirTolerant`); tests that need a 5 GiB sparse file **skip** with an explicit reason when the disk is short (`ENOSPC -> skip`) instead of failing. |
| Translations | The remaining Russian paragraphs in the EN docs were translated: `bridge-api.md` (intro, footnotes, "Contents"), `balancer-cppworker-contract.md` (R113/R108 blocks); `llm` casing normalised to `LLM`. |
| Gates | `run-checks.ps1` warns that a parallel `go test` produces environment failures; the run itself is still 4 steps: Go packages, JS, CUDA self-test, localisation and documentation gates. |

## Disk and images (local environment, not part of the code)

- Docker: unused images older than 24 h and the build cache were removed (-50 GB inside the VM);
  the active stand images were kept, but old r228/r229 tags are gone - rebuilding is required to
  roll back to them.
- Windows: the Go cache, `%TEMP%` and the npm cache were cleared; the Docker VHDX was compacted
  by the operator (76 GB free now).
- New images: `balancer`/`webui` - `r236-i18n`, `agent` - `r237-i18n`, `cppworker:gpu` -
  `r237-i18n` (with the language sync code).

## Checks

- `pwsh -File scripts/run-checks.ps1` - 4 steps, 0 failures;
- `python scripts/i18n-scan.py` - 0/0 with a budget of 0;
- `python scripts/verify-doc-pairs.py` and `scripts/verify-docs-complete.py` - 39 pairs, 0 broken
  links.

## Upgrading

The upgrade is optional: behaviour does not change, only tests, `.gitignore` and documentation.
`git pull` (branch `centurion`) is enough. Image rebuilds are needed only if you want the log
language enabled on the workers.
