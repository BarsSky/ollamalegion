пункт с местом в коде/доках, причиной и тем, что его закрывает. Источники:

**R** — нужно продуктовое решение, **E** — внешняя проверка.

## P2 — архитектура и сопровождение

12. **Два мозга на один JSON**: `/api/chat` — generic-путь, `/v1/chat/completions`
    и `/ollama/api/chat` — handler-путь (`router.go:113`); разная очередь, разные
    правила окна, разные фичи (R86 image-tools и R403 недостижимы на
    `/api/chat`). План: `refactoring-plan.ru.md`, этапы 1–7.
13. **Дублирование решений**: три предиката «это стрим?» (`proxy.go:2129`,
    `proxy_request.go:1130`, `llamacpp_translate_req.go:285` — последний
    по умолчанию `false`), 4 «очереди», 39 функций выбора бэкенда, 8 циклов
    стрима в балансере, 11 писателей стрима в воркере (из них 3 через
    `safeStreamWriter`).
14. **Мёртвый код.** **ЗАКРЫТО частично в R480:** удалены `bindSession`
    (`session_handler.go`), `acquireSlotWithRetry` и `executeWithFallback`
    (`slot_handler.go` — файл удалён вместе с тестами), `extractModel`
    (`proxy.go`), дубль `/health` из `routeRequest` (`router.go`). Осталось:
    `SetQueueManagerProxy` — no-op, но его вызывают ~200 тестов как шов
    «подними прокси с очередью»; удаление требует переписать все сценарии,
    выгоды нет — помечен как тест-шов в комментарии.
15. ~~**Устаревшее описание поверхностей**~~ **ЗАКРЫТО в R480:**
    в `backend-type-isolation.ru.md` добавлена одна актуальная таблица
    «поверхность × тип × где код» (R479-алиасы, passthrough в Ollama,
    image-поверхность, admin API).
16. **`stream:true` по умолчанию на legacy-поверхности для GET-запросов**
    (`parseRequestBody`). Видно живьём в `/api/v1/proxy/logs`: `GET /api/version`
    пишется с `"stream": true`, хотя это не стрим. Косметика для разбора
    (поле «Поток» в прокси-логах вводит в заблуждение), но менять поведение
    без отдельного решения нельзя: от этого флага зависит выбор транспорта на
    `/api/chat` и `/api/generate`. Варианты: (а) `stream` только для POST
    chat/generate; (б) оставить флаг, но в лог писать `stream_effective`
    (реально выбранный транспорт); (в) отдельное поле `transport`. Нужен выбор
    (рекомендация — (б): не меняет маршрутизацию, убирает ложь в логе).
