refactor(balancer): R59.15c — extract shared proxyRequestToBackend helper

Refactor
--------
OllamaRouter.proxyHTTP (ollama_router.go:245) and LlamaCppRouter.proxyHTTP
(llamacpp_backend_helpers.go:545) were near-duplicate 22-line implementations
of the same logic:
  • resolve backend by ID
  • resolve port via getBackendPort()
  • build target URL
  • create http.Client with timeout
  • build request with context + body
  • copy headers
  • do the request

The only meaningful difference was the HTTP client timeout:
  • OllamaRouter: 30s (Ollama endpoints are fast)
  • LlamaCppRouter: 120s (Round 21 — /api/show, /api/pull, /api/create
    trigger cppworker lazy-load which can take 50-70s for 5GB models)

Extracted to Proxy.proxyRequestToBackend(r, backendID, timeout) in
proxy_helpers.go. Both router methods are now 3-line thin wrappers:
  func (or *OllamaRouter) proxyHTTP(r, id) (*http.Response, error) {
      return or.proxy.proxyRequestToBackend(r, id, 30*time.Second)
  }
  func (lr *LlamaCppRouter) proxyHTTP(r, id) (*http.Response, error) {
      return lr.proxy.proxyRequestToBackend(r, id, 120*time.Second)
  }

No call sites change — the 7 callers (6 in llamacpp_handlers_admin.go,
1 in ollama_router_admin.go) continue to use lr.proxyHTTP / or.proxyHTTP.
