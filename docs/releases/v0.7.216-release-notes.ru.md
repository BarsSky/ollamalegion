Релиз исходников после `v0.7.211` (v1.0-rc2). Закрывает четыре темы: витрину WebUI без
стенда, рефакторинг всей документации, полную локализацию логов и ошибок и ворота, которые
не дают этим изменениям откатиться.

## Образы

В этом релизе обновляются **balancer** и **webui** (проверены локально как
`balancer:r236-i18n`, `webui:r236-i18n`). `cppworker`, `agent` и `sdworker` нужно
пересобрать, чтобы в них появился код синхронизации языка:

```bash
pwsh -File scripts/build-containers.ps1 -Balancer -WebUI -Agent -CppWorker -Tag r236
docker compose -f deployments/docker-compose.stack.yml --profile full up -d --force-recreate
```

`sdworker` собирается через compose (`--profile full build imageworker`); в образе
`imageworker:cuda-75-86-120` кода R234 ещё нет.

## Как включить язык логов

```dotenv
# deployments/.env
OLLAMALEGION_LOG_LANG=en          # ru | en | auto
OLLAMALEGION_LOG_LANG_SYNC_SEC=60 # как часто воркеры спрашивают балансер
```

или в WebUI: «Настройки → Язык логов и ошибок → Применить» (администратор). Смена
действует без перезапуска контейнеров.

## Как обновиться с v0.7.211

1. `git pull` (ветка `centurion`), затем `git submodule update --init --recursive`.
2. Пересобрать образы (см. выше) и пересоздать контейнеры.
3. Ничего в конфиге менять не нужно: `logging.language` необязателен, при отсутствии язык
   берётся из локали, при неясности — `ru`, то есть прежнее поведение сохраняется.
4. Документация: старые пути (`docs/api.md`, `docs/en/…`, `docs/ru/…`, `plans/…`)
   больше не существуют — используйте `docs/README.md` как точку входа.

## Известные ограничения

- Локализация не переводит намеренно: комментарии, промпты, уходящие **модели**, строки-маркеры
  сопоставления чужого текста и строки-факты внешних программ (llama.cpp, sd-server). Список
  и причины — `docs/development/i18n-logs.md`.
- Переключение языка действует на новые сообщения; уже записанные строки остаются на прежнем.
- Флейки тестов, замеченные в сессии: один сетевой тест `internal/balancer` и
  `TestHFBundle_FileProgressShape` на Windows (cleanup TempDir) — при повторном прогоне зелёные,
  починка отдельной задачей.
