# R60.10 — Upstream error passthrough + format based on path

> **Date:** 2026-09-07
> **Author:** Mavis
> **Trigger:** R60.5 plan §3 deferred. User said "продолжаем по списку" 2026-09-07.
> **Status:** ACTIVE (analysis complete → implementation in progress)

## 0. Bug

cppworker's HTTP errors (404, 400, 413, 500, etc.) come back to the balancer
correctly, but the balancer ALWAYS wraps them in HTTP 502 + Ollama-style
JSON body, regardless of:
1. The original HTTP status (404 from upstream becomes 502 downstream)
2. The original endpoint style (Ollama `/api/*` vs OpenAI `/v1/*`)

**Reproduction (2026-09-07, live):**
- `GET /v1/models/nonexistent` via balancer (18080):
  - Upstream cppworker: `404 Not Found` + `{"error":"model ... not found"}` (OpenAI-format)
  - Downstream: `502 Bad Gateway` + `{"created_at":"...","done":true,"done_reason":"error","error":"upstream returned HTTP 404: {\"error\":...\"}","message":{"content":"","role":"assistant"},"model":""}` (Ollama-format, broken)

**Symptoms:**
- OpenAI clients (openai-python, OpenWebUI OpenAI mode) get 502 + Ollama-format
  error instead of expected 404 + OpenAI `{"error": {"message": ..., "type": ...}}`
  format. Clients may crash or show "internal error" instead of "model not found".
- 4xx errors get re-classified as 502 Bad Gateway, breaking retry logic
  (clients may retry on 502 but should NOT retry on 404).

## 1. Root cause

`internal/balancer/llamacpp_transport_nonstream.go:377-393`:
```go
if resp.StatusCode < 200 || resp.StatusCode >= 300 {
    errBody, _ := json.Marshal(map[string]interface{}{
        "model":       modelFromCtx,
        "created_at":  time.Now().UTC().Format(time.RFC3339),
        "done":        true,
        "done_reason": "error",
        "error":       fmt.Sprintf("upstream returned HTTP %d: %s", resp.StatusCode, string(respBody)),
        "message":     map[string]interface{}{"role": "assistant", "content": ""},
    })
    w.Header().Set("Content-Type", "application/json")
    w.Header().Set("Content-Length", strconv.Itoa(len(errBody)))
    w.WriteHeader(http.StatusBadGateway)  // ← always 502, never preserves upstream status
    w.Write(errBody)
    return nil
}
```

Two issues:
1. **Status code lost**: any upstream 4xx becomes 502 (loses 404, 400, 413, etc.)
2. **Body format fixed**: always Ollama format, no OpenAI variant

Same issue in streaming path (`llamacpp_transport.go:404-462`).

## 2. Fix strategy

**Preserve upstream semantics as much as possible:**

1. **4xx upstream (400-499, excluding 408/429 which are transient):**
   - **Pass through** upstream body AS-IS
   - **Preserve** upstream status code (404 stays 404, 400 stays 400)
   - This is what HTTP semantics expect — client gets accurate error info

2. **5xx upstream (500+):**
   - **Wrap** in 502 Bad Gateway (correct semantic — gateway proxy IS at fault)
   - **Format depends on originalPath:**
     - `/v1/*` (OpenAI): `{"error":{"message":"...","type":"upstream_error","code":N}}`
     - `/api/*` (Ollama): current `{"model":"","done":true,"done_reason":"error","error":"...","message":{}}`

3. **408/429 upstream:** pass through as-is (transient — client may retry)

4. **Network errors (no response):** current behavior (502 with diagnostic)

## 3. Implementation

### File 1: `internal/balancer/llamacpp_translate_req.go`

Add helper:
```go
// isOpenAIPath — true for /v1/* paths (OpenAI-compatible API style).
// Used to choose error body format when wrapping upstream 5xx errors.
func isOpenAIPath(path string) bool {
    return strings.HasPrefix(path, "/v1/")
}
```

### File 2: `internal/balancer/llamacpp_transport_nonstream.go:377-393`

Replace 4xx-rewrap-with-502 block with:
```go
if resp.StatusCode < 200 || resp.StatusCode >= 300 {
    // R60.10 (2026-09-07): preserve upstream status for 4xx (except 408/429 which
    // are transient and pass through too). Only wrap as 502 for 5xx (gateway error).
    isTransient4xx := resp.StatusCode == http.StatusRequestTimeout || resp.StatusCode == http.StatusTooManyRequests
    if resp.StatusCode < 500 && (resp.StatusCode >= 400 || isTransient4xx) {
        // Pass through upstream body AS-IS (preserves OpenAI /v1/models error
        // format {"error":{"message":...,"type":...,"code":N}} or Ollama format).
        // Set Content-Length explicitly (avoid TransferEncodingError in aiohttp).
        w.Header().Set("Content-Type", resp.Header.Get("Content-Type"))
        if w.Header().Get("Content-Type") == "" {
            w.Header().Set("Content-Type", "application/json")
        }
        w.Header().Set("Content-Length", strconv.Itoa(len(respBody)))
        w.WriteHeader(resp.StatusCode)
        w.Write(respBody)
        logger.Get().Debugw("proxyRequestLlamaCppNonStream: passed through upstream 4xx",
            "backend", backendID, "status", resp.StatusCode,
            "original_path", originalPath)
        return nil
    }

    // 5xx: wrap in 502 with format matching originalPath.
    var errBody []byte
    if isOpenAIPath(originalPath) {
        // OpenAI-style error: {"error": {"message": ..., "type": ..., "code": N}}
        errBody, _ = json.Marshal(map[string]interface{}{
            "error": map[string]interface{}{
                "message": fmt.Sprintf("upstream returned HTTP %d: %s",
                    resp.StatusCode, string(respBody)),
                "type":    "upstream_error",
                "code":    resp.StatusCode,
            },
        })
    } else {
        // Ollama-style error (current behavior).
        errBody, _ = json.Marshal(map[string]interface{}{
            "model":       modelFromCtx,
            "created_at":  time.Now().UTC().Format(time.RFC3339),
            "done":        true,
            "done_reason": "error",
            "error":       fmt.Sprintf("upstream returned HTTP %d: %s",
                    resp.StatusCode, string(respBody)),
            "message":     map[string]interface{}{"role": "assistant", "content": ""},
        })
    }
    w.Header().Set("Content-Type", "application/json")
    w.Header().Set("Content-Length", strconv.Itoa(len(errBody)))
    w.WriteHeader(http.StatusBadGateway)
    w.Write(errBody)
    return nil
}
```

### File 3: `internal/balancer/llamacpp_transport.go:404-462` (streaming)

For streaming:
- 4xx upstream → NOT possible to return SSE (client expects streaming).
  Just return 4xx + body (non-streaming). Client handles it as normal error.
- 5xx upstream → existing SSE/NDJSON behavior.
