refactor(balancer): R59.15b — single dispatch loop via []BackendRouter

Refactor
--------
`routeRequest` had three repeated `if X != nil && X.Route(w, r)` ladders
(lines 105-127 for mixed mode, 132-136 for locked llama.cpp, 139-143 for
locked Ollama). Each ladder hand-rolled nil checks and ordering logic.

Replaced with a single dispatch pattern:
  • `buildRoutersForDispatch(bt types.BackendType) []BackendRouter` —
    builds the priority-ordered list. The order is the only thing that
    matters (it encodes all the previous conditional logic):
      - locked llama.cpp → [llamaCppRouter]
      - locked Ollama    → [ollamaRouter]
      - mixed + Ollama backends present → [ollamaRouter, llamaCppRouter]
      - mixed + only llama.cpp backends → [llamaCppRouter, ollamaRouter]
      - no backends registered → [ollamaRouter, llamaCppRouter]
  • `dispatchRouters(routers []BackendRouter, w, r) bool` — iterates the
    list, skipping nil entries, returns true on first Route match.

`routeRequest` body shrank from ~95 lines of dispatch logic to 4 lines:
  routers := p.buildRoutersForDispatch(bt)
  if p.dispatchRouters(routers, w, r) { return true }
