chore(release): v0.5.12 — SSE load progress + measured load time + WebUI auto-cleanup

Round 25 (2026-08-04). Реализует roadmap ideas из v0.5.11:
- SSE для /api/models/load/progress (real-time push вместо polling)
- Pre-flight load time estimate based on actual measured speed
- WebUI auto-poll cancel on pagehide/visibilitychange

## New: SSE load progress

cppworker: GET /api/models/load/progress/stream?model=<name> —
text/event-stream, push-events каждые 500ms с {state, elapsedMs,
loadingSizeBytes, ...}. Heartbeat :keepalive каждые 15s. Auto-close
на loaded/error/unloaded.

Balancer proxy: isSSEResponse() + streamCopy() в gguf_backend_proxy.go
стримит напрямую без буферизации. Content-Length сбрасывается,
X-Accel-Buffering=no для nginx.

WebUI GgufLoadProgress: переключился с setInterval на EventSource.
Auto-fallback на polling если EventSource.CLOSED (HTTP 4xx/5xx).
stopPolling теперь закрывает EventSource.

Auto-cleanup: pagehide + visibilitychange listeners останавливают
все polling/SSE при уходе со страницы. Без этого фоновые EventSource'ы
удерживали cppworker'а после закрытия вкладки.

## New: Measured load time cache

cppbackend.LoadTimeRecord{SizeBytes, ContextSize, DurationMs, Timestamp}.
Backend хранит thread-safe ring buffer последних 20 успешных load'ов.
Backend.EstimatedBytesPerSec() вычисляет weighted average (старые
записи >7d фильтруются, edge cases SizeBytes/DurationMs=0 пропускаются).

estimateLoadTimeMs в cppworker использует measured speed если история
не пустая, иначе fallback на 100 MB/s хардкод.

Live impact: после первого load'а Qwen3 (2.5GB, 99s) estimate
становится ~70s вместо хардкода 28s. Более реалистично для клиента.
