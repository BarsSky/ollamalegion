## 3. Известные ограничения (Known Limitations)

Не планируются к реализации в текущем релизе.

| # | Ограничение | Причина | Где задокументировано |
|---|---|---|---|
| KL-1 | Ollama `images[]` в `/api/generate` | cppworker не поддерживает multimodal | `docs/api.md` |
| KL-2 | `context` (base64 KV-cache) между запросами | KV-cache не сохраняется между инференсами | `docs/cppworker-model-params.md` |
| KL-3 | `keep_alive` таймер unload | unload выполняется по `applyKeepAlive`; полный TTL-таймер не реализован | `docs/api.md` |
| KL-4 | Agent → Ollama runtime config | Ollama не имеет публичного REST API | `docs/troubleshooting.md` |
| KL-5 | `ollama pull <name>` для cppworker | нет Ollama registry → HTTP 501 | `docs/api.md` |
| KL-6 | Точная `modelLoadFeasibility` | требует GGUF metadata parser llama.cpp | `docs/metrics.md` |
| KL-7 | `rpc_coordinator` и `virtual_router` режимы | каркас создан, pipeline execution не завершён | `docs/configuration.md` |
